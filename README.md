# Magnat Flower

Внутренний сайт учёта цветочного магазина: склад, букеты, продажи, возвраты, расходы и ежедневные отчёты в кыргызских сомах.

Исходники приложения и инструкции находятся в [shop](shop/README.md).

Сайт использует сервер и базу Cloudflare D1. GitHub хранит исходники; GitHub Pages не подходит для запуска серверных API и базы данных. Текущая конфигурация публикации рассчитана на Sites.

Рабочая база, аккаунты, секреты и локальные резервные копии в репозиторий не включены.
